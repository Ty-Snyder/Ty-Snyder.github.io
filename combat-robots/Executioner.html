Executioner

15lb Combat Robot

Project Overview

A project done in collaboration with the Placer Robotics Combat Program. Executioner was a small team project with Dorian Todd and Colin Malone. We used Autodesk Fusion for a fully custom CAD, which we spent countless hours working on and innovating from version to version. We ordered a waterjet-cut aluminum frame, then used a drill press, 3-axis CNC and tapping equipment to get the frame assembled properly. The weapon is 4340 steel, which was EDM'ed to shape and then heat treated to harden it.

Key Features

  • Bent Titanium Front Corners: Protect from horizontal weapons.
  • Tall Ears: Allow the bot to drive upside down and still reach full spin up.
  • 4 lb Egg Beater Weapon: Egg beater designs help optimize MOI, which combined with a lot of weight lets the weapon store a lot of energy.

Technical Specifications

Weight Class 15lb (Dogeweight)
Weapon Type 4340 Steel Egg Beater
Weapon Speed 11,000 RPM
Drive Speed 10 ft/s
Chassis 6061-T6 Aluminum
Armor Grade 5 Titanium and UHMW
